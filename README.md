# CRUD Java + PostgreSQL

Projeto CRUD desenvolvido em Java utilizando JDBC e PostgreSQL.

## Funcionalidades

- Cadastrar usuário
- Listar usuários
- Atualizar usuário
- Deletar usuário

## Tecnologias

- Java
- JDBC
- PostgreSQL
- Maven

## Objetivo

Projeto criado para praticar operações CRUD e integração entre Java e banco de dados PostgreSQL.
